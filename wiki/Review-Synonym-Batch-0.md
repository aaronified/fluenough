# Review: English synonym sets, batch 0 (poke-holes pass)

Source of truth: this wiki page. Issue #924, ADR-0050. Date 2026-10-30.

Rule applied: a set stays only if every member is the same lemma spelled
differently, with no sense, part of speech, register or technical use where
the meanings differ. When in doubt, drop. Result: 218 sets in, 201 kept,
17 dropped. The format was checked (quoted, sorted, no word in two sets, no
set clashes with the closed UK/US doubled-l list).

## Dropped

| Set | Counterexample |
|---|---|
| analog / analogue | US "analog" is the signal type, "analogue" the counterpart; usage splits by sense |
| burned / burnt | inflected forms; "burnt sienna", "burnt offering" are not "burned" |
| cipher / cypher | "cypher" is also a hip-hop circle and a query language; not one word in all uses |
| criticisation / criticization | rare, not attested in standard dictionaries |
| dialog / dialogue | "dialog box" (computing) vs conversation; US keeps the two apart |
| dreamed / dreamt | inflected forms |
| enquire / inquire | British usage: enquire = ask, inquire = formal investigation |
| enquiry / inquiry | as above ("public inquiry") |
| leaned / leant | inflected forms |
| program / programme | UK: "program" is computing only, "programme" a broadcast or plan |
| smelled / smelt | "smelt" is also to melt ore, and a fish |
| spelled / spelt | "spelt" is a grain |
| spilled / spilt | inflected forms |
| spoiled / spoilt | inflected forms; "spoilt" as adjective (a spoilt child) |
| speciality / specialty | UK splits them (a speciality of the house vs a medical specialty) |
| toward / towards | two different words (towards carries the adverbial -s); "toward" also an old adjective |
| whiskey / whisky | convention marks different spirits (Irish and US vs Scotch) |

## Kept after questioning

ketchup / catsup (same sauce, one word two spellings), gaol / jail, donut /
doughnut, axe / ax, amoeba / ameba, adviser / advisor, plough / plow, savour
/ savor, judgement / judgment, theatre / theater, skeptic / sceptic, hiccup /
hiccough, and every -ise / -ize lemma pair (applied to lemmas only; the
grader derives the inflected forms). The plural-only pairs pajama(s) /
pyjama(s) stay because the plural is the usual lemma.
