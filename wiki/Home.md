# Fluenough wiki

Fluenough is a language-agnostic drilling app for basic language skills. A language is data, not code.

This wiki is the source of truth for its documentation. Every page links to the others. Links stay on GitHub, apart from a few named official sources.

Code and decks live in the [repository](https://github.com/aaronified/fluenough). Report problems in its [issues](https://github.com/aaronified/fluenough/issues).
