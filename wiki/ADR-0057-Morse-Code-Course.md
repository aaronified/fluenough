# ADR-0057: Morse code is a notation course, taught by sight and by ear

Source of truth: this wiki page.

- **Status:** Proposed (owner request, 2026-11-20: "add a morse code course, similar to braille, script only. Use sound and the dot -- symbols."). The choices below are defaults for the owner to confirm.
- **Date:** 2026-11-20

## Context

English Braille ([ADR-0043](ADR-0043-English-Braille-Course)) is a course on a script with no speech of its own. Morse code is the same kind of course, with one difference: it is learned by ear. Text-to-speech cannot say a dot or a dash, so the sound has to be the real tones.

## Decision

1. **A notation course.** The language block is `{ code: "qmo", iso639_3: "zxx", script: "morse", icon: "•–" }`. `qmo` is in the local-use range `qaa` to `qtz`; `zxx` ("no linguistic content") is the IPA's code, since Morse writes the letters of any language. It is `script_only` (Read and Write, no Speak or Hear), `typed: false` (answers are chosen, as the IPA's are) and `culture: false` (no culture bar). `isMorse` joins `isNotation`, so it has no voice, is learned only when chosen, is placed by nothing and is Complete once its path is written.
2. **Symbols.** A card's `target` is its pattern in `•` (dot, U+2022) and `–` (dash, U+2013), both in the bundled Roboto, so no system font is used. They are the symbols Morse tables print, and they are not typed: no phone keyboard has them in one place. Production therefore chooses among patterns. A typed Morse keyboard, like braille's, is a later step if the owner wants one.
3. **Sound is the card's own recording.** Each card has `audio: decks/qmo/audio/<card id>.opus` ([A card's own recording](Deck-Format#a-cards-own-recording-audio)), played by the existing `speakCard`. The files are generated, not recorded: a 600 Hz sine at 15 words per minute with 5 ms ramps, in the ITU timing of one unit for a dot, three for a dash, one between the signs of a character, so each file is one character. The credit is `license: "CC0-1.0"`, `credit: "Generated by tools/make_morse_course.py"`. The tool `tools/make_morse_course.py` makes them, with the deck files; they download with the deck and play offline.
4. **Content.** Source: Recommendation ITU-R M.1677-1, International Morse code (2009): the 26 letters, 10 digits, the punctuation and signs it lists, and its procedural signs (understood, error, wait, end of work, starting signal), plus SOS from the ITU Radio Regulations.

## Consequences

- The released app does not know `morse`, so the language is in `decks/min_app.json` and older apps skip it.
- Listening is drilled from the recording, and Speaking is left out of every card (`modes: ["speaking"]`), as braille's is.
- "Slower" plays the recording at 0.7 times its speed, which changes its pitch; a slower Farnsworth-style spacing is not offered.
