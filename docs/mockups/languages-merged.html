Languages

One page for the languages you know and the ones you are learning, by skill. Each skill is one tap-to-cycle control with three states: Know, Learn, Leave. Everything on the phone is live: tap through it. Notes, the dialect and script table, the contrast self-check and the open choices: languages-merged.md.

Things to try

  • Tap a skill's control: it cycles Leave, Know, Learn, Leave. Know is instant. Learn on a language with no full decks asks to download them first (one Learn skill means the full decks).
  • Marathi: Write is Know but not checked, so it offers no review cards. Tap Check to review, answer the three questions, and Review decks then offers the script.
  • Assamese is Know only, with review decks on the phone. Set Read to Leave: the sheet says the review decks go at the next app open.
  • Gujarati is all Leave with decks still on the phone. Press Simulate: the app opens again and it goes.
  • Add a language, search "urdu", "বাংলা" or "east", set skills, then Add. Onboarding is one step with the same controls.
