Languages

One page for the languages you know and the ones you are learning, by skill. Each skill is one pill: tap it to change Leave, Know, Learn. Checks and review decks appear only when Review is on in Settings (or the Review control above). Everything on the phone is live: tap through it. Notes, the dialect and script table, the contrast self-check and the open choices: languages-merged.md.

Things to try

  • Settings has a Review switch (default off). Turn it on: a Know skill in a language whose level is not found says "Fit your level to be able to review". Off: that line goes away.
  • Tap a skill's logo pill: it cycles Leave, Know, Learn. Every change shows a toast. Learn on a language with no full decks asks to download them first.
  • Set Speak, Hear, Read or Write to Learn: the bottom button reads Check. It tests the sound or whether the script shows on this phone. Use "Sound test" and "Script on this phone" above to see both outcomes. Changing the skill away from Learn needs no check.
  • Marathi (Review on): Know, level not found. Tap Find my level on the sheet: the subtext goes and the button reads Fit my level. Assamese has its level found.
  • Assamese (Review on) is Know only, with a review deck on the phone. Set Read to Leave: the sheet says the review decks go at the next app open.
  • Assamese: set its last skills to Leave, one by one. The language goes back to the pool and disappears from the list (Undo is offered); Add a language finds it again.
  • The list's filter pills scroll sideways. The deck update check, the i and the cross are at the top of a sheet; deck size and the last update check are behind the i.
  • Add a language, search "urdu", "বাংলা" or "east", set skills, then Add. Onboarding is one step with the same controls.
