# Contributing to Fluenough

Thank you for considering it. Fluenough is a language-agnostic drilling app —
the whole premise is that a language is *data*, not code, so the most valuable
contributions are often content rather than software.

The full guide is in the wiki. Start with the page that matches what you want to do:

- [Contributing](https://github.com/aaronified/fluenough/wiki/Contributing): ways to help, pull requests, review and licensing of contributions.
- [Deck building guide](https://github.com/aaronified/fluenough/wiki/Deck-Building-Guide): adding or fixing deck content.
- [Translation guide](https://github.com/aaronified/fluenough/wiki/Translation-Guide): translating the app's text and the deck English layers.
- [Development setup](https://github.com/aaronified/fluenough/wiki/Development-Setup): building, testing and the checks before a pull request.
- [Reporting a problem](https://github.com/aaronified/fluenough/wiki/Reporting-a-Problem): how to report a bug.
- [Agentic coding](https://github.com/aaronified/fluenough/wiki/Agentic-Coding): how coding agents work in this repository. The rules are in [AGENTS.md](AGENTS.md).
