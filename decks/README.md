# Decks

Deck content, one YAML file per deck, organised by language code.

A deck may be a core and its layers. The core holds the language learnt; each
layer holds one native language's meanings, notes and labels. Every deck is on
its language's path, `<lang>-path.yaml`, which lists the decks in teaching order.

The full guide is in the wiki:

- [Deck building guide](https://github.com/aaronified/fluenough/wiki/Deck-Building-Guide): the layout, cores and layers, paths and B1 plans, step by step.
- [Romanising Indic languages](https://github.com/aaronified/fluenough/wiki/Romanising-Indic-Languages): how readings are written for each language.
- [Deck licences and quoted books](https://github.com/aaronified/fluenough/wiki/Deck-Licences-and-Quoted-Books): the licence terms, and quoting books, songs and films.
- [Deck format](https://github.com/aaronified/fluenough/wiki/Deck-Format): the format summary; the full file is [docs/DECK-FORMAT.md](../docs/DECK-FORMAT.md).
